## Methods compared

|-----|--------|---------------------|--------------|
| **BOLFI-all** | `final_result/all/` (per-dataset best seed — see `reproducible_setting.md`) | `--simulator_type all`: Gumbel + argmax over **all J** alternatives. `llk_mode=trust`, `tol_quantile 0.85` both retrievals, `DEMetropolisZ(scaling=5e-4)` | J{100,200,500} x N{10k,20k,50k}, P10, D5+6, SIM30 |
| **BOLFI-SA** | `final_result/SA/` | `--simulator_type SA`: Multiple-Try Metropolis on the discrete choice, per-slot deterministic RNG (reproducible under threaded batch eval), `llk_mode=trust` | same |
| **Gibbs-MTM** | `compare_estimators_across_configs.ipynb` (cached; `results_pymc_prior/…prot2_mtm_steps5000`) | PyMC data-augmentation Gibbs, Protocol 2 (chosen vs 1 sampled competitor), MTM m=5, 5000 draws, prior-based | J{100,200,500} x N{10k,20k,50k} x P{10,20,40} |

- BOLFI has two GP-retrieval points: **`iter_max`** (GP at max BO iters) and **`early_stop`**.
- `covered/10` = # betas whose true value is inside the HDI (BOLFI 94%, Gibbs 95%).
- `RMSE`/`MAE`/`bias` = posterior-mean error vs true, averaged over the P betas.
- **Best (highest `early_stop` coverage) run kept per dataset.** The only thing that differs between datasets of one method is the training seed; the seed-41 re-trains were done for the configs where seed 42 landed on a bad part of the near-flat cuisine-ASC ridge (section 6).
  - BOLFI-all seed 41: **J100/N10k, J200/N50k, J500/N10k**  (seed 42 elsewhere)
  - BOLFI-SA  seed 41: **J200/N20k, J500/N10k**  (seed 42 elsewhere; seed 41 was *worse* for J500/N20k)
- Both methods now use one consistent code version + the `trust` MCMC likelihood, so this is a clean all-vs-SA comparison.
- Gibbs numbers are transcribed from a notebook's cached output (no raw traces on disk), a *different* experiment (Protocol-2 binary likelihood, prior-based) — indicative, not controlled.

## 6. Why some datasets use seed 41 instead of 42

The 7 cuisine alternative-specific constants are identified only via the small omitted reference category (Ethiopian restaurants, ~2.3% of J200 choices, ~3.9% for J100/J500). The stage-1 discrepancy is nearly **flat** along "shift all 7 cuisine ASCs by a common delta", so BOLFI's best acquired point can park anywhere on that ridge — the entire error in a failing config is a common offset across all 7 cuisines, with `rating / cost / log_dist` essentially exact.

Which point of the ridge the BO lands on is **seed / trajectory dependent** — the same behaviour in both simulators. Re-seeding is a per-dataset fix, not a guaranteed one:

| method | seed-41 helped | seed-41 neutral | seed-41 *hurt* |
|--------|----------------|-----------------|----------------|
| BOLFI-all | J100/N10k (`||best-true||` 0.37->0.15), J200/N50k (0.89->0.34) | J500/N10k | — |
| BOLFI-SA  | J200/N20k (0.81->0.11, cov 3->10), J500/N10k (0.41->0.31) | — | J500/N20k (0.42->0.75, cov 6->2) |

A durable fix has to be structural (kill the ridge): `--sim_num 100`, a weakly-informative prior on the cuisine-ASC level, or whitening the stage-1 attribute discrepancy. See `reproducible_setting.md` section 4.

## Reading the comparison

- **Coverage** = does the interval contain the truth; **RMSE/MAE** = how close the point estimate is; **post.sd** = how tight (confident) the posterior is. Lower sd with worse coverage = over-confident / biased.
- `r_hat` <= ~1.01 and `ess_bulk` in the hundreds ⇒ the MCMC summary is trustworthy.

### Bottom line (best seed per dataset, `early_stop`)

- **BOLFI-SA now edges out BOLFI-all** — mean coverage **93% vs 90%**, mean RMSE **0.071 vs 0.083**. SA gained the most from the seed-41 re-trains (J200/N20k 3->10, J500/N10k 6->10) and it already handled **J200/N50k** (10/10) where BOLFI-all stays stuck at 6/10.
- `iter_max`: same ordering, wider gap (SA 88% / 0.065 vs all 79% / 0.073) — BOLFI-all's `iter_max` posteriors are the tightest and so least forgiving of any residual bias.
- **Gibbs-MTM** is still nominally best (97% / 0.052) but on a different (Protocol-2, prior-based) setup and 5000 full draws — not a like-for-like cost comparison.
- **Remaining weak spot (both BOLFI simulators):** J200/N10k — 90% (all) / 60% (SA) — a cuisine-ridge config not yet re-seeded. BOLFI-all also can't get J200/N50k past 6/10 at either seed.
